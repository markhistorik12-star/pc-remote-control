# Android APK Build Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a signed Android APK from the Capacitor project using Gradle commands

**Architecture:** Use existing Gradle wrapper and android.yml configuration, build locally without CI

**Tech Stack:** Android SDK, JDK 17, Gradle wrapper

**Spec:** android.yml - Android build configuration

## Global Constraints
- JDK 17 must be installed and configured
- Android SDK with API 34+ must be available
- Gradle wrapper must be executable
- Use existing android.yml configuration
- Build in frontend/android directory

## Review Focus
- Gradle wrapper permissions allow execution
- Android SDK components are installed (platform, build-tools)
- keystore configuration exists for signing
- gradlew commands work without network issues

---

**Files:**

- Verify: `frontend/android/gradle/wrapper/gradle-wrapper.jar`

**Interfaces:**
- Consumes: Existing android.yml config

### Task 2: Configure Signing (si se necesita firma)
**Files:**
- Modify: `frontend/android/app/build.gradle`
- Create: `keystore.properties` (si no existe)

**Interfaces:**
- Consumes: Signing config requirements
- Produces: Signed APK capability

- [ ] **Step 1: Write failing test**

```bash
./gradlew assembleRelease > /dev/null 2>&1 && echo "BUILD SUCCESS"
```

- [ ] **Step 2: Run test to verify it fails (si no hay firma)

Expected: BUILD FAILED - missing signing config

- [ ] **Step 3: Add signing configuration**

Edit `app/build.gradle`:
```gradle
signingConfigs {
    release {
        storeFile file('keystore.jks')
        storePassword System.getenv('KEYSTORE_PASSWORD')
        keyAlias 'key0'
        keyPassword System.getenv('KEYSTORE_PASSWORD')
    }
}

buildTypes {
    release {
        signingConfig signingConfigs.release
    }
}
```

- [ ] **Step 4: Verify test passes**

```bash
./gradlew assembleRelease
```

- [ ] **Step 5: Commit**

```bash
git add frontend/android/app/build.gradle
git commit -m "feat: configure APK signing"
```
